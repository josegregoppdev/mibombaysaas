# MOBILE-FIRST PLAN — MiBombay

## Goal
System designed first for phone, then for tablet/desktop (mobile-first).
Small restaurants use the phone as their main tool.

## Current diagnosis (July 21, 2026)

| Page | Mobile today | Action required |
|---|---|---|
| Landing | OK | Minimal touch-ups |
| Login / Auth Cards | OK | No changes |
| Registration | OK | No changes |
| Dashboard | Sidebar takes 25% width on mobile | Redo with Offcanvas |
| CSS media queries | Only 3 rules in max-width: 768px | Rewrite mobile-first with min-width |

## Implementation

### 1. Dashboard — Sidebar as Offcanvas (Bootstrap 5)
- Current sidebar hides on mobile with d-none d-md-block
- Add Offcanvas (slide-in from left) with hamburger button in header
- On md+ sidebar remains fixed as it is now
- Reference: https://getbootstrap.com/docs/5.3/components/offcanvas/

### 2. CSS Mobile-First
- Change @media (max-width: 768px) rules to @media (min-width: 768px) with desktop overrides
- Adjust dashboard padding/margins for mobile
- Ensure correct visuals from 320px

### 3. Touch targets (accessibility)
- Buttons and links with minimum 44x44px on mobile
