# Today — 2026-08-11

Session log: Supplier module (encrypted CRUD) + default supplier (isDefault) for demo and new companies.

## Objective
- Build the complete Supplier module: CRUD with AES-256-GCM encryption for document and phone, masked values in the list, pagination + filters, active toggle.
- Add a protected default supplier (`Proveedor Principal`) auto-created for the demo restaurant and every new company.

## Important Details
- Java 21, Spring Boot 4.1.0, Thymeleaf, Bootstrap 5.3, MySQL, MapStruct, Lombok.
- User communicates in English (B1), prefers Spanish for quick questions.
- Supplier mirrors the Customer module's encryption scheme: `documentEncrypted`/`phoneEncrypted` (AES-256-GCM) + `documentLookupHash`/`phoneLookupHash` (HMAC-SHA256).
- Unlike Customer, Supplier is now fully mirrored: default supplier protected exactly like Consumidor Final.
