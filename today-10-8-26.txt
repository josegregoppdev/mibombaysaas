## Work State
### Completed

- **Product entity**: Added `currentStock` and `minimumStock` (BigDecimal, default ZERO) to `Product.java`.
- **ProductDTO**: Added `currentStock` and `minimumStock` with `@PositiveOrZero` + `@Digits(8,4)` validation.
- **ProductService**: ADICIONAL now requires recipe (throws if `recipeId` null). Stock defaults on create. Stock preserved on update if null.
- **Repositories**: Added `findByTenantIdAndIdIn(String tenantId, Collection<Long> ids)` to `IngredientRepository` and `ProductRepository`.
- **InventarioService** (NEW): `consumeForSale(Sale)` — the only service allowed to modify stock. Creates `Movement` records of type `SALE` for every ingredient and SIN_RECETA product affected. Handles:
  - CON_RECETA/ADICIONAL: decrements recipe ingredients.
  - SIN_RECETA: decrements product stock.
  - Combo expansion: decomposes into products and applies same rules.
  - Exclusions: `"Without: ingredient1, ingredient2"` skips excluded ingredients.
  - Negative inventory: controlled by `TenantConfiguration.allowNegativeInventory`.
  - Transactional: all in same transaction as sale confirmation.
- **SaleService.confirmSale()**: Now calls `inventarioService.consumeForSale(sale)` after setting state CONFIRMADA and before save. All in one transaction.
- **SaleService.createSaleFromCart()**: Fixed `findById` → `findByIdAndTenantId` for products, combos, and cashier. Added tenant validation for cashier.
- **InitialDataConfig**: 
  - `createDemoRecipes`: Now idempotent (each recipe guarded by `existsByCodeAndTenantId`). Added EXQ-001 (Extra Cheese: 1 unit cheese) and EXL-001 (Extra Lettuce: 0.020 kg lettuce).

  - Added `ensureAddonRecipesLinked()`: repairs existing demo products to link recipes.
  - Added `ensureSIN_RECETAStock()`: adds stock to existing SIN_RECETA products if missing.
- **product/form.html**: Added stock card (currentStock + minimumStock) visible only for SIN_RECETA. Recipe section now required for ADICIONAL.
